Offline QR code studio

Make a QR code that keeps working.

Everything happens in this page. Nothing is sent anywhere, and you can check that by turning your network off and using it anyway.

What this file does

Network
None. There is no fetch, XMLHttpRequest, WebSocket, EventSource or sendBeacon in this file, and its security policy refuses every connection.
Storage
None. It keeps no cookies, no local or session storage, no database and no cache. A library is a file you save yourself.
